- **운영 주체**: 꿈식판 (이석훈, ggumsikman@gmail.com)
- **타겟**: 제주도 자영업자 100명 풀에서 시작 → 전국 확장
- **참고 기획서**: `OneDrive\문서\카카오톡 받은 파일\자영업자 성장형 구독플랫폼\자영업자_성장형_구독플랫폼_개발기획서 (1).docx`

## 톤

- **전문성 / 신뢰감**. 마케팅 대행이 아닌 성장 플랫폼.
- **솔직성** = 신뢰. "보장하지 않는 것" 명시 (매출/방문/노출 X).
- 다크/뉴트럴 베이스 + 차분한 골드 액센트. 식판 메타포 X.
- Serif 헤드라인 + Pretendard body로 강한 위계.

## 1페이지 구조

```
HERO         — 한 줄 가치 제안 + 가격 카드 (10만원/월)
01 POSITIONING — 우리가 하는 일 / 안 하는 일 (do / don't)
02 FEATURES   — 매월 받으시는 9가지
03 FLOW       — 작동 방식 4단계
04 BRAND PAGE — 핵심 자산 미리보기
05 MATCH      — 인플루언서 매칭 (별도 비용 명시)
06 PRICING    — 월 10만원 단일
07 FAQ        — 9개 (성과 보장? 광고 대행? 협업비? 등)
08 CONTACT    — 무료 상담 CTA + 사업자 정보
```
