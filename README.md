# 꿈식판 BIZ

가람이 영업용 1페이지 비즈니스 사이트.

- **메인 사이트**: https://ggumsikpan.vercel.app (꿈식판 정체성/식판/꿈식맨)
- **이 사이트** (BIZ): 시스템 컨설팅 전문 회사 톤. 사업 영역·실적·팀 중심.

## 톤

- 회사형 (1인 컨설턴트가 아닌 "전문 회사")
- 협업 파트너 이름 비공개 (대표 이석훈만 실명, 나머지 총괄은 영역명만)
- "협업/콜라보" 단어 미사용
- B2B 진중함 + 결과 중심

## 구조 (1페이지 단일 스크롤)

01 사업 영역 — 4 패키지 (자동화/대시보드/통합/엔터프라이즈)
02 진행 프로세스 — 5단계
03 실적 / 사례 — 시스템 8개
04 4 총괄 팀 — 모노그램 (시·기·디·검)
05 가격 — 시작/운영 + 케어 플랜
06 시작하기 — 무료 카톡 상담 CTA + 사업자 정보

## 배포

Vercel 새 프로젝트로 배포 예정. 권장 도메인:
- `ggumsikpan-biz.vercel.app` (무료 서브도메인)

## 자산 일관성

- 디자인 토큰: 메인 사이트와 동일 (`--orange #F37021` 외)
- 폰트: Pretendard / Gowun Batang / JetBrains Mono
- CSS는 메인 사이트의 style.css 기반 + biz 전용 추가 (`.team-card-mono`, `.biz-hero`, `.biz-trust-row` 등)
